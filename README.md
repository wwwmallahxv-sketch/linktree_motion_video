# Linktrees.link explainer video

A vertical (1080×1920), 80–120 second Arabic motion graphics video explaining linktrees.link to business owners. Built with HyperFrames and Claude Code on the web.

- `PROMPT.md`: the creative brief. Paste it into Claude Code to start.
- `CLAUDE.md`: workflow rules Claude Code follows in this repo.
- `assets/`: put `voiceover.mp3` and `music.mp3` here when they're ready.
- `renders/`: the latest preview and the final video, ready to download.
